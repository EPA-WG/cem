cem-element demo

Legacy Material demo. This compatibility gallery is retained during migration. Use the canonical cem-action component in cem-components for new work.

cem-action is the canonical action from @epa-wg/cem-components, loaded by <cem-element>. This page retains the Material example gallery based on the Material Design specification for buttons.
Action triggers the flow by changing the data slice or following the href attribute URL. Inspired by MUI

Visibility uses the native HTML hidden attribute. See the shared visibility convention.

Attributes

label provides fallback button text when no child content is supplied. Child text or icons replace that fallback.
class specific: cem-bend-sharp, cem-bend-smooth(default), cem-bend-round.
variant selects primary, explicit, contextual, alternate or destructive (danger).
disabled disables the native button by attribute presence.

Shape tokens set sharp corners, smooth corners and round ends through --cem-action-border-radius. Round ends use half the theme's control height. The taller multiline example supplies a local --cem-shape-height and round-bend binding.

Hover the enabled action, hold the pointer or Space to see pressed paint, and use Tab to see the keyboard focus ring. Disabled actions suppress activation and keep their disabled colors.

Child icons supply the visible content. Use aria-label to name icon-only actions for assistive technology.

Alternate actions use the theme’s enthusiasm palette.

Contextual actions use the theme’s comfort palette.

Compare all five CEM action intents. Hover, press or Tab to an enabled control to compare its states. Each row uses one intent across sharp, smooth and round shapes. Disabled examples are in the Interaction states sample.
