A command with the menuitem role, disabled state, and disclosure-state reporting. It complements cem-action and cem-icon-button; the containing menu owns navigation, focus, and any expanded content.

Property playground · Automated stories

Hover each enabled control, hold a pointer press, and use Tab for keyboard focus. States below are real component attributes. The five theme rows stay fixed so you can compare the same states side by side.

Disabled and hidden use presence. Expanded reports disclosure state; the containing menu or disclosure owns navigation and open content. Clicks record activation without toggling selection.

Public attributes and slots

  • href
  • aria-label

href creates a leaf navigation anchor. aria-label names the control separately. The submenu slot accepts a nested cem-menu; owners remain buttons. Use root keyboard="menu" to enable popup interaction. A cem-dropdown can wrap a full menu.
