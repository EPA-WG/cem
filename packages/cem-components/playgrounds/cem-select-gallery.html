Property playground · Automated stories

Hover each enabled control, hold a pointer press, and use Tab for keyboard focus. States below are real component attributes. The five theme rows stay fixed so you can compare the same states side by side.

Open dropdowns with click or Arrow keys; Enter commits, Escape cancels. Multiple listboxes use Space or click to toggle choices. Disabled options are skipped. Public option and option-group payloads support selected, disabled, value, labels and rich content.
