A trigger and positioned panel for arbitrary content. Compose cem-menu and cem-menu-item inside the panel for nested command navigation; use cem-select for value selection.

Property playground · Automated stories

Public attributes and slots

  • label
  • open
  • disabled
  • aria-label
  • hidden
  • class
  • dir

label supplies fallback trigger text (Dropdown). open="false" closes the panel; other values open it, preserving source visibility semantics (default true). disabled and hidden use presence. aria-label names the fallback trigger separately. class and dir are supported. The base slot replaces the trigger; the default slot supplies panel content.

Use native click, Enter or Space to toggle, ArrowDown to open and focus, Escape to close and restore focus. Tab and outside activation dismiss without a trap. Menu leaf activation dismisses the complete popup chain. Exercise real hover, press, keyboard focus and expansion.
