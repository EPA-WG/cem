A persistent named region for nearby tasks and filters. Applications can control its visibility without moving focus. Use cem-dialog when the task needs native dialog presentation and focus management, and cem-field for editable content.

Property playground · Automated stories

Public attributes and slots

  • label: Visible heading and default region name; defaults to Sheet.
  • transient: Absent: persistent. Present (including false): application-controlled visibility.
  • expanded: Presence shows a transient region; ignored for a persistent region.
  • aria-label: Separate accessibility-only name; leaves visible text unchanged.
  • aria-labelledby: ID references for an authored heading; takes precedence over aria-label.
  • aria-describedby: ID references for supporting instructions.
  • hidden: Native host visibility.
  • class: Consumer composition hooks.
  • dir: Inherited ltr or rtl writing direction.

The default slot holds the retained body. The label slot replaces visible fallback markup; use an explicit ARIA reference when that markup supplies the region name. Hover and focus belong to the authored controls. The sheet has no disabled, invalid, pending, readonly or selected state; those states belong to its controls.
