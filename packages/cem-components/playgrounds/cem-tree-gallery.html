A keyboard-navigable hierarchy whose expansion and selection remain distinct. Use cem-list for a flat collection or cem-nav for navigation links.

Full examples and variation matrix · Property playground · Automated stories · Shared project navigation declaration

Public attributes and slots

required label, expanded-values, selected-values, selection (none/single/multiple), loading-label (Loading), disabled and silent expandedValues/selectedValues; recursive cem-tree-item payloads require unique token value and label and accept expandable, disabled and loading. Class, hidden and dir use native host behavior. Boolean attributes use presence, including empty and false-valued attributes.

Public attribute inventory

Up/Down, Home/End and typeahead move focus. Right/Left open, close or traverse parent/child relationships. Enter/Space toggles a branch or emits leaf activation; application selection remains unchanged.
