cem-icon: Full examples and variation matrix

A passive icon with optional adjacent content, supporting Unicode, image URLs, Font Awesome, and Material Icons. Use cem-icon-button for an interactive icon command or link, and cem-action for a general action.

Property playground · Automated stories

image takes precedence over name, including an empty value which hides the icon. Without either attribute, the icon is circle. Values shorter than three Unicode code points render as text; otherwise a slash selects an image, fa- selects Font Awesome, and other values select Material Icons. Font icons require the corresponding stylesheet, loaded by these demos.

label names the icon with one image role. Without a label the icon is decorative. Default slot content remains accessible independently. Icons have no click, hover, focus, selected, or disabled behavior; the containing action owns interactive states. Color is inherited. Hidden uses attribute presence.
