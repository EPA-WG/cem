A passive icon with optional adjacent content, supporting Unicode, image URLs, Font Awesome, and Material Icons. Use cem-icon-button for an interactive icon command or link, and cem-action for a general action.

Property playground · Automated stories

image selects the glyph; an empty value hides it. Without image, the glyph is circle. Values shorter than three Unicode code points render as text; otherwise a slash selects an image, fa- selects Font Awesome, and other values select Material Icons. Font icons require the corresponding stylesheet, loaded by these demos.

label supplies visible fallback text (empty by default). Default-slot payload replaces it, preserving markup. aria-label names the glyph with one image role; otherwise the glyph is decorative. Migrate accessibility-only uses of label to aria-label. Default slot content remains accessible independently. Icons have no click, hover, focus, selected, or disabled behavior; the containing action owns interactive states. Color is inherited. Hidden uses attribute presence.
