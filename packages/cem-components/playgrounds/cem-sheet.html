A persistent named region for nearby tasks and filters. Applications can control its visibility without moving focus. Use cem-dialog when the task needs native dialog presentation and focus management, and cem-field for editable content.

Full examples and variation matrix · Automated stories

Persistent sheets stay visible regardless of expanded. With transient present, expanded controls visibility; even the text false counts as present. Visibility never moves focus. Tab into the draft to exercise native focus and typing; Escape does not close the region. Blank optional fields omit the attribute. The projected-label example below shows authored markup; label remains the default region name, with aria-label or aria-labelledby available separately.
