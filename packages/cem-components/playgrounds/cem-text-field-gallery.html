Use cem-textarea for multiline entry. A labeled text-entry control with help content, validation, and borderless state indicators. It shares the same input and form contract as cem-field; pair it with cem-action to submit or reset a form.

Property playground · Automated stories

Hover each enabled control, hold a pointer press, and use Tab for keyboard focus. States below are real component attributes. The five theme rows stay fixed so you can compare the same states side by side.

Both fields remain borderless. Enabled, unfocused controls keep a subtle resting indicator. Hover changes its color; focus adds a separate stripe. Busy preserves editing; disabled, readonly, required and busy use attribute presence, including the text false. Invalid is an ARIA string.
