Slots: trigger supplies one native control or control provider; label replaces visible fallback text. The default body is eager; body can supply an inert template and close replaces the generated close control.

Use Tab, Escape, pointer hover and native button activation. Five fixed theme rows compare supported states. Dialog modality is explicit; tooltip hover delays apply only to pointer interest. Disabled flags use presence, including the text false. Unsupported invalid, readonly and selected task states are not synthesized.
