cem-icon-button: Full examples and variation matrix

An icon button or link supporting image URLs, Material Icons, Font Awesome, and visible content. Use href for navigation; cem-action supplies form submission and reset, while cem-menu-item supplies menu commands.

Property playground · Automated stories

Hover each enabled control, hold a pointer press, and use Tab for keyboard focus. States below are real component attributes. The five theme rows stay fixed so you can compare the same states side by side.

Disabled and hidden use presence. Expanded reports disclosure state; the containing menu or disclosure owns navigation and open content. Clicks record activation without toggling selection.

Use href for navigation, icon for an image URL, Font Awesome classes or a Material icon name, and direction for row or column layout. Kind accepts normal, primary, secondary, alert and blend; these share primary link colors as in the legacy implementation. Font icons require their provider stylesheet. Button mode uses contextual colors.
