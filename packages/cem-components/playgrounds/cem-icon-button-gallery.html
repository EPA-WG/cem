cem-icon-button embeds cem-icon inside a native button or link and applies CEM action-theme states, including selected, pending, disabled and keyboard focus. Use href for navigation; cem-action shares the variant, state, bend and native form APIs, while cem-menu-item supplies menu commands.

Embedded cem-icon and shared attributes

cem-icon-button embeds cem-icon inside a native button or link and loads it automatically. It relays image, size, direction, label, aria-label, class, hidden, and default-slot content. Unicode, emoji, image URLs and font glyphs use the same rendering as cem-icon.

Attribute note: label supplies visible fallback text; projected content replaces it. For an icon-only control, use aria-label without label. aria-label names both the control and embedded glyph and takes precedence over the control’s label name.

image selects the glyph. An explicitly empty source hides the glyph. Without a source, buttons show circle and links show no glyph. size="small|medium|large|x-large|xx-large" sets action control height and is forwarded unchanged to the icon. Small and large select their icon sizes; other values use the default icon size. Normal or absent size inherits control height. The inherited --cem-icon-size, --cem-icon-size-small, and --cem-icon-size-large tokens control glyph size. Row and column layouts work in both modes.

href, disabled, selected, selectable, pending, variant, and activation remain owned by cem-icon-button. Present href selects a link; absent href selects a button.

Action theme support

Controls use the same action state model and theme tokens as cem-action: default, hover, active press, disabled, pending, selected and keyboard focus. Variant selects primary (default), explicit, contextual, alternate or destructive action colors in both modes. These states respond to all five CEM theme modes and inherited action-token overrides.

selected keeps the theme’s selection stripe visible, including while disabled or pending. selectable exposes an unselected button choice. The containing application controls selection. pending="true" shows busy feedback and takes precedence over hover, press and disabled paint; disabled still prevents activation. Keyboard focus has an independent stripe. Contrast themes use action contours, reduced motion freezes pending animation, and forced colors use system-color indicators.

Hover each enabled control, hold a pointer press, and use Tab for keyboard focus. States below are real component attributes. The five theme rows stay fixed so you can compare the same states side by side.

Disabled, selected, selectable and hidden use presence. Pending uses true or false. The containing application owns selection; clicks record activation without changing selected.

Use href for navigation, image for a Unicode glyph, emoji, image URL, Font Awesome classes or Material icon name, and direction for row or column layout. Variant selects the same action intent in both modes. Font icons require their provider stylesheet.
