cem-theme-switch: Full examples and variation matrix

A theme selector for light, dark, native, and contrast modes that applies the chosen theme to its child content. Use it around components such as cem-action, cem-field, and cem-select to compare their themed appearance.

Property playground · Automated stories

Hover each enabled control, hold a pointer press, and use Tab for keyboard focus. States below are real component attributes. The five theme rows stay fixed so you can compare the same states side by side.

Mode accepts light, dark and native (default); contrast applies only in light and dark. Native follows system colors and disables the contrast checkbox. Each example has its own radio name. The default slot preserves child content while switching.

Public attributes and slots

  • mode
  • contrast
  • name
  • hidden
  • class

Slots: The default slot contains the content whose theme is controlled.
