A native checkbox for independent choices, including mixed aggregate state. Related choices: cem-radio · cem-switch. Use cem-field for text input.

The default slot replaces label text. The required-marker slot replaces the visible marker and remains aria-hidden. aria-label and aria-labelledby name the input separately; aria-describedby and aria-errormessage reference authored help and errors. Name and form define the native form owner; checked changes the native checked default. Boolean presence includes empty values and false. Invalid uses the explicit string true. Indicator supports outline and underline; unsupported values fall back to outline. Readonly is not supported by native checkable inputs.

Use real pointer hover, Space and Tab to compare focus with checked state. Radios also support native arrow navigation. Busy does not disable the control or delay changes. Indeterminate is a presence flag that sets the native mixed property; activation clears it, and an unchanged flag does not reapply it during unrelated renders.
