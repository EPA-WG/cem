# CEM Events Projection Schema

This package defines the semantic CEM event-stream projection layer:

- schema URL: `https://cem.dev/ns/projection/events/1`
- primary content type: `application/vnd.cem.events+cem-bin`
- debug/interchange view: `application/vnd.cem.events+json`

The events projection is designed for replay, multicast, and incremental
consumers. JSON output remains a view over this event layer.

## Validation Examples

The schema-owned examples live in [`examples/`](examples/) and are used by the
CLI validation integration tests.

| Example | Content type | Purpose | Expected result |
| --- | --- | --- | --- |
| [`basic-events.cem-bin`](examples/basic-events.cem-bin) | `application/vnd.cem.events+cem-bin` | Canonical binary event projection generated by `cem-ml convert --to-format events-bin`. | Pass |
| [`basic-events.events.json`](examples/basic-events.events.json) | `application/vnd.cem.events+json` | Minimal events JSON debug view with open, separator, value, and close events. | Pass |
| [`nested-events.events.json`](examples/nested-events.events.json) | `application/vnd.cem.events+json` | Event stream for a nested CEM source with names, values, separators, and close events. | Pass |
| [`invalid-kind.events.json`](examples/invalid-kind.events.json) | `application/vnd.cem.events+json` | Events JSON item with an unsupported event kind. | Fail with `cem.projection.events.json_shape` |
| [`invalid-binary.cem-bin`](examples/invalid-binary.cem-bin) | `application/vnd.cem.events+cem-bin` | Binary projection with an invalid magic header. | Fail with `cem.projection.events.binary_magic` |

Validate a binary projection explicitly:

```bash
cargo run -p cem-ml-cli -- validate \
  --content-type application/vnd.cem.events+cem-bin \
  --schema https://cem.dev/ns/projection/events/1 \
  packages/cem_ml/schema-packages/cem-events-projection/v1/examples/basic-events.cem-bin
```

Validate a JSON debug view explicitly:

```bash
cargo run -p cem-ml-cli -- validate \
  --content-type application/vnd.cem.events+json \
  --schema https://cem.dev/ns/projection/events/1 \
  packages/cem_ml/schema-packages/cem-events-projection/v1/examples/basic-events.events.json
```
