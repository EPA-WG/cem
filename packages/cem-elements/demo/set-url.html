Set URLs

Write browser location declaratively

A location-element with method and src writes the page URL. Supported methods mirror location.href, location.hash, location.assign(), location.replace(), history.pushState(), and history.replaceState().

Render a writer only in response to deliberate state or an event. A writer whose target already equals the current URL is inert, preventing repeated renders from producing duplicate history entries.
