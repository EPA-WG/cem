XPath XML tables and trees

Query the same nodes in different views

Edit local XML to explore its names, values and relationships. The separate XPath library reads native XML through cem-data @projection=xpath. CEMT presents the results as a table or a recursive tree. fn:local-name() and fn:namespace-uri() distinguish equal names in different namespaces.

The table sorts with CEM-QL seq:sorted. XPath still navigates each original node: its previous sibling is unchanged by the display order. Select a row by its unique authored @id, then change the order. The tree exposes attributes and coalesces adjacent text and CDATA into one text node.

These small XML views complement the generic multi-format viewer. HTTP XML integration and standard XPath fn:sort remain later work. XML inputs are limited to 32 KiB, 64 levels and 4096 events; XPath text and work limits also apply. Invalid XML replaces the view with a reader error.
