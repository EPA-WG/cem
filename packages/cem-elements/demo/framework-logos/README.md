# Framework logo demo fixtures

These local SVG files keep the relative-image cases in `hex-grid.html`
deterministic when it is opened as a standalone page or source-loaded by
Storybook. The demo deliberately retains the legacy full React image URL as
its full-URL resolution case.

The React, Angular, Semantic UI, Flutter, Refine, Bootstrap, Vue.js, Lit,
Redux, Svelte, SolidJS, and Next.js marks were downloaded from
[Simple Icons](https://simpleicons.org/) on 2026-09-06. Simple Icons data is
published under CC0; the individual marks remain trademarks of their owners.

`open-wc.svg` was downloaded from the image URL used by the legacy
`@epa-wg/custom-element` demo. `wc-square.svg` is a local copy of the
repository-owned DCE logo in the parent demo directory.
