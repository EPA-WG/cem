cem-element demo

NPM versions

Choose a package version from registry data

The reusable template loads package metadata with http-request and queries the imported CEM nodes to populate a native select. It supports a current version, optional publication dates, a projected label, value propagation, and synchronization with the page hash.

This demo uses a small same-origin registry fixture so every case remains deterministic and works offline. It is a compact version/date list; a live registry endpoint also needs XPath functions for its response vocabulary and host authorization for that origin.

package
Package name shown by the picker.
initialversion
Version selected after the records load.
showdate
Set to true to append publication dates.
value
Reflects the latest user selection.
label slot
Overrides the default package label.
