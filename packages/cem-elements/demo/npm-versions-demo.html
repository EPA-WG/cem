cem-element demo

NPM versions

Choose a package version from registry data

The reusable template loads package metadata with http-request and turns the version records into a native select. It supports a current version, optional publication dates, a projected label, value propagation, and synchronization with the page hash.

This demo uses a small same-origin registry fixture so every case remains deterministic and works offline. Replace its request URL with an allowed NPM registry endpoint in an application that permits that origin.

package
Package name shown by the picker.
initialversion
Version selected after the records load.
showdate
Set to true to append publication dates.
value
Reflects the latest user selection.
label slot
Overrides the default package label.
