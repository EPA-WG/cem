XPath function libraries

Share a query across templates

A template's xpath-functions reference loads a separate named function library. CEM-QL passes declared scalars or explicitly selected XML nodes to XPath; ordinary slice bindings and CEMT rules keep the page reactive. Edit an example to see the result change.

The templates share the compiled library. Its URL resolves from the declaration document, and each input keeps its own state and focus. Libraries are limited to 32 KiB and 64 functions; library imports are not supported yet. Each call also bounds text to 1 MiB per intermediate or final value and shares a finite work budget across its nested expressions.

For XML, cem-data @projection=xpath exposes the native document to the library. The reader reuses unchanged XML across renders, retains up to 16 documents per compiled template, and reports invalid input without a partial result. Each XML source is limited to 32 KiB, 64 levels and 4096 events.
