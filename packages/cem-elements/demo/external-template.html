Loading DCE template by SRC attribute

Load declarations from reusable sources

A cem-element src can select a template in this document, load a whole external document, or select its #fragment. Relative dependencies resolve from the source file, not its consumer.

A named declaration is reusable; omitting tag renders an anonymous instance in place. Payload remains the fallback when a source or fragment is missing. Imported document scripts are not executed.

CEM-ML is the preferred template format. The XSLT examples demonstrate the bounded compatibility path: whole stylesheets use their XSLT media type; embedded stylesheets use an explicit template lang="custom-element-v0" wrapper. Selecting an ID alone does not opt unannotated markup into XSLT execution.
