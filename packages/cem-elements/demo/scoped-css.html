cem-element demo

CSS scoping contract

Executable samples for private, named-shared, instance, static, fragment, and anonymous CSS ownership.

Private CSS uses native @scope (<cem-tag>); named shared CSS uses the public declaration-owned scope="name"; payload CSS uses an implicit parent-rooted @scope. An explicit uid-seed stabilizes internal render identity and rewritten keyframe names; it does not create a CSS boundary. Internal data-cem-render-scope is not a CSS hook, and no per-instance CSS marker is generated.
