cem-element demo

Override a data cell with template matching

Import the viewer, replace one presentation

Each example owns a small template that imports the existing data viewer, declares one template @match rule, and calls base.viewer. The viewer dispatches each column heading through apply-templates @mode=cell, passing that row's values as cells. Its @match=true rule produces the default td; a matching local rule can replace the whole cell.

The first sample includes its entire template inline. Its rule is simply node == "name" in cell mode: node is the column heading. The replacement cell contains an image plus the original name. The name's pokemon-id attribute supplies the image ID, as in the index's Pokémon example. Other fields keep the imported presentation.

The separate stock rule demonstrates a content override in inspect mode, keeping the default cell. It uses a narrower condition: /catalog/product/stock with trimmed text 0. Its CEM-QL predicate checks namespaces and data:node_key membership in that source path, so a reference branch's stock stays ordinary.

Editing, table discovery, columns, sorting and row selection all come from the base viewer. The first sample replaces cell generation; the second replaces matching content within a cell. CEM-ML imports the source into a retained CEM tree; presentation leaves that source intact. Edit the source, then Tab out to rerender.

Cell mode also receives attribute headings such as @id and direct-text headings such as #text. It runs once per column even when that row has no value. The default rule shows ∅ for missing values, "" for empty values, and delegates retained child nodes to inspect mode. The existing viewer's import and query limits apply.

The Pokémon sample supplies an ID on each name and uses the two bundled images, IDs 2 and 3. These local SVGs come from the same pinned sprite package used by the HTTP demo; see the image sources and attribution. cem-module-url resolves their directory relative to the declaration, including when this page is source-loaded.
