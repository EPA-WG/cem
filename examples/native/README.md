# Native parity fixtures

The web, SwiftUI, and Compose fixtures render the same primary action and comfort-surface card from generated CEM
tokens. `component-guidance.json` owns the cross-platform name, state, token-family, accessibility, and parity contract
verified by the `@epa-wg/cem-theme:verify:native-platforms` Nx target.

The web fixture is the credential-free visual reference for Phase 8. Live Figma canvas review remains in Phase 10;
Phase 8 verifies that every sample token resolves from the same canonical CEM build without claiming a reviewed Figma
frame.
