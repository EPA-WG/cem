## Limits and sequencing

The complete deployment remains the default. This change makes no new download,
memory-saving or general standards-conformance claim. SCSS expansion retains its
existing explicit resolver/execution policy; same-schema SCSS source export is
unavailable. Relax NG support validates schema
source rather than arbitrary instance documents. Optional-profile XSLT source
parsing/formatting works through admitted contracts; CEM-QL's contextless bundle
compiler still refuses missing schemas until its explicit contract integration
is implemented. Complete-profile bounded XSLT execution stays available.

Studio UI stays declarative. New parser behavior belongs to the native shared
engine; no Studio parser, component-local JavaScript, new UI capability or token
is introduced. Entered credentials still block recovery until explicitly cleared,
and automatic whole-Studio recovery remains disabled. Loader, source, checkpoint,
allocation and retirement limits/deadlines are unchanged. Tests use isolated
browser state and do not open or clear saved user projects or drafts.

The functional **Content types and schemas** catalog now leads the remaining
Studio queue. Native compiler/reader/provenance and release diagnostics remain
explicit follow-ups after that sample work.
