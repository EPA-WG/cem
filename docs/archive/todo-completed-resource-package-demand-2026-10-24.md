`http-request`. The ordinary complete deployment remains the default.

  No source bytes, replacement grants, native owners or recovery authority leave
  the native planner. Request decoding, memory admission and source limits remain

- [x] Add shared bounded `CemSchemaAssetDemandGroup.prepare(plan, signal)` outside
  the native work queue. Empty plans acquire nothing; repeated demand reuses
  committed activation; lazy physical clients replay the retained requirements.
  Cancelling one caller stops its waiter while group-owned publication finishes
  before later work. Closing an already prepared physical host cannot skip a
  remaining participant. Actual publication failures still fence the group.

  native execution/import or navigation publication. Snapshot bytes and resource

  and block recovery during preparation. Stale selections cannot replace newer

  publication without modifying the draft.

  enrollment. Project/URL/status data cannot authorize replacement. Other
