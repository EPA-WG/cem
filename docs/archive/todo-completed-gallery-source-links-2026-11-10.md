# Gallery canonical source links

The [October migration](todo-completed-canonical-source-2026-10-24.md) supplied
the XHTML filenames in the playgrounds. The current audit checked 85 viewers
across 59 component property playgrounds and the galleries that include a
viewer. The icon documentation now uses the full document specifier. The
source editor and workspace playgrounds gained direct links beside their
existing viewers.

The focused browser gate resolves the folder import maps in the workspace
and in isolated npm archives. It checks that each viewer displays the exact
canonical XHTML fetched by its link and that the template belongs to the
expected component. The media-preview fixture includes a template with
`capability="live-preview"`.

Gallery startup exercised native host publication of the public
`data-cem-density` and `data-cem-spacing` defaults. Native verification
covered an explicit spacing override and refusal of authored island and CSS
context markers. All 26 focused native host-publication and stylesheet
tests passed, along with 85 viewer checks in each browser layout.
