## Delivered behavior

Native-only `structural_receiver::application::mixed` binds a verified CEMMRC1
declaration to an actual borrowed `FreshStructuralHost`, a registered original
receiving capture, exact original scalar projections and caller-held installed
CEMAPPD3 roots. Original names, count text, scalar models/source maps, root/graph
owners, readiness and directed grants are checked. The original receiving type
selectors run through the ordinary resolver against the actual host; a borrowed
adapter supplies only the exact expected compiled root. No substitute host,
fabricated reference or JSON AST handoff is introduced.

Consumption is explicitly field-only. Structural nodes use private native field
snapshots and the existing SC1 receiver and native attribute-reference validator.
Other source fields retain their pending state; no whole-input model is exposed
or published as ready. Scalars use the existing closed conversion/facet policy,
intersect original local facets and revalidate typed inspection data. Executable
fields consume exact native roots with local count intersections. Typed ingress
requires the compiled descriptor's explicit typed-only profile; absence of
lexical facets does not grant it. Unsupported local executable facets refuse.

Executable preparation and receipt consumption share the existing issuer seal,
remaining budgets and original rule/operation contexts. Tokenization/preparation
is not replayed during consumption. Local cardinality diagnostics spend the same
diagnostic allowance. Original input arenas/attribute IDs and receipt issuers
must still match, including when inspecting token spans. A tokenizer readiness
callback retiring the group cannot release late spans.

One liveness/busy guard covers all receivers and required weak roots. Publication
and consumption borrow the actual host exclusively and renew original receiving
selectors; results are checked again before return. Read-only availability is
owner/epoch liveness rather than a frozen selection receipt. Peer/root/native
owner loss, context changes, closure and cancellation invalidate the group.
Atomic slot replacement preserves the previous installation on candidate
failure. Clearing, replacing or abandoning a group retires its guards and
receipts without retiring reusable parent roots or compilations. Retained
receipts keep no compilation or native callback owner alive.

Scalar source identities remain trusted native embedding assertions, checked
against actual registered arenas and exact model projections. The API does not
claim to reconstruct raw source bytes from a projection or establish permission
from a hash. Existing SC1 receiver bounds, original parser/native pending states,
legacy formats and all runtime-admission flags remain unchanged.
