## Product repairs and complete contracts

The existing preview transport previously treated any MIME containing `cem` as
text. Canonical compiled projection fixtures can contain entirely valid UTF-8,
so this incorrectly exposed them in the source editor. The shared preview/text
policy now refuses the declared `+cem-bin` family before text decoding. Ordinary
catalog sources and saved sources agree; binary results/downloads keep exact
bytes. A failing browser regression reproduces the bug with UTF-8-compatible
bytes before the repair.

The same preflight finds RELAX NG compact sources classified as unknown downloads
while saved workbenches already support them as text. The shared policy now
recognizes their declared MIME. The Node preflight checks every catalog resource,
with a browser regression for the compact source presentation. No source grammar
or native data import is implemented in JavaScript.

Two stale HTML goldens are corrected to the actual native writer bytes: Login's
526-byte output (including its trailing spaces) and Supplier's 376-byte output
(without an extra newline). Login's three native render paths match the exact
fixture. The existing fixture-specific Git whitespace policy preserves the
writer's bytes. Native CLI indents abstract JSON graph outputs while worker
publication is compact; acceptance compares their complete explicitly requested
JSON values and retains each host's actual bytes.

The CEM-QL native-node query already declares its opaque identities nonportable.
A bounded probe confirms that only its three `identity` fields change between
fresh owners, both within one heap and after offline reload. Native code derives
them from an arena address. Acceptance checks every other exported field,
including complete source-map frames, original source URI/ranges, order and
representation. It excludes only those declared opaque identity fields from
cross-owner equality and records the actual per-run export hashes. Serialized
identities never become source owners or execution input.

Generic Markdown previously selected CommonMark when no variant was declared,
so ordinary README tables remained paragraphs. The shared native default now
selects GFM, preserving explicit CommonMark and the existing unknown-variant
warning/fallback. CLI, WASM and Studio retain the declared MIME and use the same
native parser. Table-start events retain their original lexical table range;
the shared CEMT formatter emits it once instead of losing separators, alignment,
escapes and inline markup during source formatting. Native source/formatter
checks pass 39 cases and the CLI Markdown cohort passes 33, including the actual
CEM-QL README. The shared source-preview browser regression verifies all 14
configuration rows as a semantic HTML table and explicit CommonMark as valid
literal text. The same table is verified at the reported localhost Studio URL;
rebuilt-deployment online/offline acceptance is recorded below.

The long combined suite exposed missing editable controls in module maps. The
selector remains valid; an isolated module/configuration run passes. A focused
regression with 46 ordinary saved copies reproduces the blank editor with native
memory-admission refusals while `pageerror` remains empty. Controls transport
still included unused legacy workspace trees and configuration choices. Its
projector now carries active-resource state and the declaration's validation
summary only; full service/results data remains owned there. Native limits and
reserved recovery headroom stay unchanged. The rebuilt populated-workspace
regression passes with all 46 independent saved projects and 1,130 resources
unchanged, an attached editable source control and enabled validation action.
Bounded native diagnostics now accompany failure capture without exporting
editor, draft or entered form values. The combined navigation result is recorded
below.
