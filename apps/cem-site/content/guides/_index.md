# Guides

The guide hierarchy follows a Hugo-like content tree while CEM-ML remains the
build authority. Each published route is an explicit branch in the checked-in
graph rather than an implicit directory copy.

## Start here

1. Browse the complete [public package and crate index](/packages/).
2. Use the canonical [CEM-ML browser and Node CLI guide](/guides/cem-ml/cli/).
3. Review the [CEM-ML transform graph reference](/reference/cem-ml/transform-config/).
4. Compare the [WASM runtime package contract](/reference/cem-ml/wasm-runtime/).
5. Review the pinned [Angular Material coverage comparison](/components/angular-material/).
6. Try the production [interactive examples](/examples/interactive/).
7. Use [site search](/search/) for stable links into published headings.
8. Return to the [CEM Site root](/).

Additional guides will render their canonical package or repository sources
without duplicating those sources inside the site application.
